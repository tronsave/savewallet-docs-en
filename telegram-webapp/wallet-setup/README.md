# Wallet Setup

The **SaveWallet Telegram WebApp** is a lightweight wallet that runs right inside Telegram — no installation needed. It's self‑custodial too: your keys are generated for you and protected by a passcode.

Get started with the official bot: [@savewalletofficial\_bot](https://t.me/savewalletofficial_bot)

* [How to create a wallet](how-to-create-a-wallet.md)
* [How to import a wallet](how-to-import-a-wallet.md)
* [How to export a wallet](how-to-export-a-wallet.md)

{% hint style="warning" %}
Back up your recovery phrase as soon as you create a wallet, and never share it or your passcode with anyone.
{% endhint %}
